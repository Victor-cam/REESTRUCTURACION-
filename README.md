## Despliegue en GitHub Pages

Para publicar el proyecto:

1. Subir el código al repositorio de GitHub.
2. Ingresar a "Settings".
3. Seleccionar "Pages".
4. En "Source", elegir:
   - Branch: `main`
   - Folder: `/ (root)`
5. Guardar los cambios.
6. Esperar unos minutos mientras GitHub genera el sitio.

## Flujo de trabajo GitHub Flow

Durante el desarrollo se utilizaron ramas independientes para cada funcionalidad:

- feature/estructura-carpetas
- feature/pagina-contacto
- feature/pagina-nosotros
- feature/estilos
- fix/rutas-relativas

Los cambios fueron integrados mediante Pull Requests y revisados antes de fusionarse con la rama principal.

## convenciones de commits 

Este proyecto sigue [convencional commits] (https://www.conventionalcommits.org/es/)

Formato 
<tipo>: <descripcion breve en minusculas>

tipos permitidos en este documento 
feat: se agrega una nueva funcionalidad
fix: se corrigr un error o bug 
docs: Cambios solo en documentación (README, comentarios, etc.)
style: Cambios de formato, espacios, indentación (sin afectar la lógica)
refactor: Reorganización de código sin agregar funciones ni corregir errores
